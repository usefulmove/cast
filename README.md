# Cast

Design harness for a better command-line playback interface for asciinema `.cast` recordings.

Current status: enso harness bootstrapped; active work is `docs/stories/STORY-001-controlled-playback-cli-design.md`.

The likely product is a `cast` CLI focused on demo-grade playback control: pause, step, seek, marker navigation, and predictable rewind.

A second design seam is emerging: compile Pi session trees into `.cast` playback projections, keeping Pi JSONL as canonical semantic state.
